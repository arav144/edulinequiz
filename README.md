# edulinequiz

Online Student Examination and Assessment Platform for Eduline Publishers.

## 🚀 Architecture
- **Frontend**: Next.js 14 App Router, React 18, Tailwind CSS, Interactive Canvas Floating Physics, Lucide Icons.
- **Backend**: Express REST API, MongoDB Mongoose, JWT Admin Authentication, PDFKit Single-Page Certificate Engine.
- **Admin Panel**: Built-in SPA at `/admin` route with real-time statistics, question bank, and certificate downloads.
